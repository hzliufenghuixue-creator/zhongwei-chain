# 中微链证｜互联网部署版 MVP v3

运营主体：中微区块链技术（深圳）有限公司

这是一个适用于 GitHub Pages 的纯前端产品流程展示版，包含：

- 首页 / 平台服务 / 存证验证 / 关于平台
- 用户注册：手机号、姓名、身份证号码
- 无短信验证码、无密码的简化演示登录
- 注册前分步阅读并确认《用户服务协议》《隐私政策》
- 用户中心：账户信息、授权记录、我的存证
- 服务授权确认页
- SHA-256 演示数据指纹与存证详情
- 公开存证验证
- 独立、较完整的用户服务协议与隐私政策页面
- 移动端自适应

## 重要说明

本项目是 GitHub Pages 静态演示版本：

1. 不连接生产数据库。
2. 不连接真实区块链节点。
3. 不进行真实身份认证。
4. 登录仅采用手机号 + 身份证号匹配，属于演示功能，不适合作为生产级认证方案。
5. 演示账户及记录使用浏览器 LocalStorage 保存。
6. 请勿填写真实身份证号码、银行卡号、验证码、密码或其他敏感信息。
7. 正式生产环境上线前，应根据真实业务场景重新设计身份认证、授权、个人信息保护、安全存储、审计及数据生命周期管理方案，并由专业人员完成合规审核。

## GitHub Pages 部署

将 `index.html`、`style.css`、`app.js` 放在仓库根目录，进入 GitHub：

`Settings → Pages → Build and deployment → Source: Deploy from a branch → main → /(root) → Save`

等待 Pages 部署完成后即可访问项目地址。
