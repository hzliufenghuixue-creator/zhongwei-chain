# 中微链证｜数字存证与授权服务平台

运营主体：中微区块链技术（深圳）有限公司

这是一个适用于 网站 的数字存证与授权服务平台网站，包含：

- 首页 / 平台服务 / 存证验证 / 关于平台
- 用户注册：手机号、姓名、身份证号码
- 无短信验证码、无密码的简化账户登录
- 注册前分步阅读并确认《用户服务协议》《隐私政策》
- 用户中心：账户信息、授权记录、我的存证
- 服务授权确认页
- SHA-256 数据指纹与存证详情
- 公开存证验证
- 独立、较完整的用户服务协议与隐私政策页面
- 移动端自适应

## 重要说明

## 网站 部署

将 `index.html`、`style.css`、`app.js` 放在仓库根目录，进入 GitHub：

`Settings → Pages → Build and deployment → Source: Deploy from a branch → main → /(root) → Save`

等待 Pages 部署完成后即可访问项目地址。


本包基于上一版网站页面，仅替换《服务条款》和《隐私政策》页面正文为用户提供的原始文档内容；其余页面与功能保持上一版不变。
