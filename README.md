# 中微链证｜互联网部署版 MVP

主体：中微区块链技术（深圳）有限公司

这是一个纯静态、低成本的互联网展示版网站。

包含：
- 企业官网首页
- 注册
- 登录
- 用户中心
- 授权确认及授权记录
- 我的存证展示
- 存证验证
- 本地浏览器数据保存

## 最简单部署方式

### Cloudflare Pages
1. 注册 Cloudflare。
2. Pages -> Create a project。
3. 选择上传本项目文件。
4. 上传 `index.html`、`style.css`、`app.js`。
5. 发布后即可获得 `xxx.pages.dev` 互联网地址。
6. 后续可以绑定你自己的域名。

### GitHub Pages
把三个网站文件上传到一个公开仓库，然后开启 Pages，也可以获得互联网访问地址。

## 重要说明

本版本为了最低成本，没有接真实数据库、短信验证码、真实区块链或真实数据查询接口。
注册、授权和存证记录仅保存在用户自己的浏览器 localStorage 中。

如果用于正式业务，需要将账号、授权记录和存证记录迁移至服务端数据库，并增加 HTTPS、账号安全、隐私政策、用户协议、日志审计等措施。

网站中的“区块链/存证”描述应以实际部署能力为准，不建议对外宣传尚未实际提供的真实上链、真实客户数量或实际业务数据。
